# 导入指南：微软拼音 / 搜狗输入法

> **只是想用词库？** 去仓库首页的 **Releases** 下最新的 `astock-ime-vYYYY.MM.DD.zip`，
> 解压后照着 zip 里的 `README-导入说明.txt` 做就行，不必往下读。
> 下面写给“要自己生成一份”的人，菜单路径在新旧版本里叫法不同，找不到入口就用
> 输入法设置里的**搜索框**搜「短语 / 词库 / 导入」。

先跑一次构建，`dist/` 里会有全部产物：

```bash
python build.py all
```

下面每一节都写清「用哪个文件」。

---

## 1. Windows 自带输入法（微软拼音）

**用文件：`dist/ms_pinyin_astock.dat`**（用户自定义短语，二进制）

### Win11（23H2 / 24H2）
1. 任务栏右下角「中」图标 **右键** → **词库和自学习** → **用户自定义短语** → **管理** → **导入**；
   （入口因版本略有差异，也可以走：设置 → 时间和语言 → 语言和区域 → 中文(简体，中国) → 输入法(微软拼音) → 选项）
2. 点 **导入**，选择 `ms_pinyin_astock.dat` → 确认；
3. 想留后路的话，导入前先点一次 **导出**，把原有自定义短语备份下来。

### Win10
设置 → 时间和语言 → 语言 → 中文(简体，中国) → **选项** → 微软拼音 → **词库和自学习** → **用户自定义短语** → **管理/导入**。

### 旧版（微软拼音 2010 / 必应输入法时代）
**用文件：`dist/ms_pinyin_astock.xml`**（`dctx` 词库 XML）。

### 验证
任意输入框（记事本即可），切成微软拼音，依次敲：

| 输入 | 期望候选里出现 |
|---|---|
| `payh` | 平安银行 |
| `ndsd` | 宁德时代 |
| `wka` | 万科A |
| `stml` | ST美丽（原生 `.dat` 路径去掉了星号） |

> 说明：`.dat` 里 5552 条短语，导入后**候选顺序 = 文件写入顺序**。
> 想要热门票排前面，用 `python build.py all --freq hot`（需要行情表），它会按近 20 个交易日成交额给词频。

---

## 2. 搜狗输入法（Windows）

**用文件：`dist/custom_phrase_astock.txt`**（UTF-8 带 BOM，CRLF，行格式 `编码,词频=词语`）

1. 搜狗设置 → **输入** → **自定义短语** → **直接编辑配置文件**；
2. 把 `custom_phrase_astock.txt` 的**全部内容**替换进 `PhraseEdit.txt`，保存即生效；
3. 覆盖之前先把原来的 `PhraseEdit.txt` 备份一份，回滚全靠它。

条目多、只想留自选股或最活跃那批时：

```bash
python build.py build --stocks "平安银行,300750,宁德时代"   # 只导自选股，按你写的顺序
python build.py all --freq hot --limit 800                  # 只导近 20 日成交额前 800
```

> 不走 `.scel` 细胞词库：缩写编码本来就该由「自定义短语」承担，
> 而深蓝 3.4 的 scel 导出实测有损（5552 条回读只剩 2 条），细节见
> [formats.md 第 5 节](formats.md#5-关于-scel搜狗细胞词库)。

---

## 3. 清库 / 回滚

| 输入法 | 删除方式 |
|---|---|
| 微软拼音 | 「管理用户自定义短语」里删掉本项目导入的条目；或把导入前「导出」的备份再导回去 |
| 搜狗 | 用备份的 `PhraseEdit.txt` 覆盖回去（或在自定义短语面板里逐条删） |

**别把两次构建的产物重复导入**，会出现两份一样的候选。想全量重导：先删干净，再导一次。

---

## 4. 常见问题

**Q：导入后输入编码没反应？**
A：搜狗——确认 `PhraseEdit.txt` 真的保存了（开着自定义短语设置界面时另存会覆盖你的替换）；
微软拼音——确认导入的是本次生成的 `.dat`。两边都建议换个**新输入框**试：
有些程序的输入框会留着旧的候选记忆。还是不行就用 `--limit 300` 生成小词库单独导入定位。

**Q：`stml` 出来的不是 `*ST美丽`？**
A：微软拼音这条路：深蓝会丢弃以 `*` 开头的词面，所以 `.dat` 里是清洗过的 `ST美丽`
（见 formats.md 第 4 节）。搜狗这条路：`custom_phrase_astock.txt` 里 `*ST美丽` 和 `ST美丽`
两条都写着，能进几条就上屏哪条。非要 `.dat` 也保住官方名称，只能换别的转换工具或改深蓝源码。

**Q：候选里一堆股票挤在一起（`zykj` 有 13 只）？**
A：A 股重名是常态：`zykj` = 中一科技 / 中英科技 / 掌阅科技 / 长阳科技 … 用 `--freq hot` 让你常交易的热门票排前；
或者直接 `--exclude-st` + `--limit` 把长尾砍掉。

**Q：想要「输代码出名称」？**
A：`python build.py all --code-alias`，会追加 `000001 → 平安银行` 这类条目（词库会变大，按需开启）。

**Q：手机端呢？**
A：本项目只管 Windows 上的微软拼音和搜狗。`ms_pinyin_astock.dat` 是微软拼音专属格式，
手机上用不了；真要在手机上用，挑一个支持「自定义短语」批量文件的输入法，
按它的格式吃 `custom_phrase_astock.txt`（行格式 `编码,词频=词语`）即可。
