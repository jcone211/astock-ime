# 导入指南：三种输入法

> **只是想用词库？** 去仓库首页的 **Releases** 下最新的 `astock-ime-vYYYY.MM.DD.zip`，
> 解压后照着 zip 里的 `README-导入说明.txt` 做就行，不必往下读。
> 下面写给“要自己生成一份”的人，菜单路径在新旧版本里叫法不同，找不到入口就用
> 输入法设置里的**搜索框**搜「短语 / 词库 / 导入」。

先跑一次构建，`dist/` 里会有全部产物：

```bash
python build.py all
```

下面每一节都写清「用哪个文件」。

---

## 1. Windows 自带输入法（微软拼音）

**用文件：`dist/ms_pinyin_astock.dat`**（用户自定义短语，二进制）

### Win11（23H2 / 24H2）
1. 托盘右键「中」→ **设置**（或：设置 → 时间和语言 → 语言和区域 → 中文(简体，中国) 右侧 `···` → **输入法(微软拼音)** → **选项**）；
2. 进入 **词库和自学习** → **用户自定义短语** → **管理用户自定义短语**；
3. 点 **导入**，选择 `ms_pinyin_astock.dat` → 确认；
4. 想留后路的话，导入前先点一次 **导出** 把你原有短语备份下来。

### Win10
设置 → 时间和语言 → 语言 → 中文(简体，中国) → **选项** → 微软拼音 → **词库和自学习** → **用户自定义短语** → **管理/导入**。

### 旧版（微软拼音 2010 / 必应输入法时代）
**用文件：`dist/ms_pinyin_astock.xml`**（`dctx` 词库 XML）。

### 验证
任意输入框（记事本即可），切成微软拼音，依次敲：

| 输入 | 期望候选里出现 |
|---|---|
| `payh` | 平安银行 |
| `ndsd` | 宁德时代 |
| `wka` | 万科A |
| `stml` | ST美丽（原生 `.dat` 路径去掉了星号） |

> 说明：`.dat` 里 5552 条短语，导入后**候选顺序 = 文件写入顺序**。
> 想要热门票排前面，用 `python build.py all --freq hot`（需要行情表），它会按近 20 个交易日成交额给词频。

## 2. 微信输入法

微信输入法是按「词库」方式工作的：导入汉字词后，它自己会生成拼音编码（含简拼），
所以 **只要词进去了，敲 `payh` 就能出「平安银行」**。

### 首选：纯词表
**用文件：`dist/wechat_astock_words.txt`**（UTF-8 带 BOM，一行一个股票名）

* PC 端：托盘/系统托盘右键微信输入法 → **设置中心** → **词库**（或「语言/词库管理」）→ **导入词库 / 导入本地词库** → 选该 txt；
* 手机端（微信输入法 App）：**我的** → **输入法设置** → **词库管理** → **导入本地词库** → 先通过微信/QQ 把 txt 传到手机，再选中导入。

### 备选：带编码的词表
如果你的版本要求「词 + 拼音」两列：

**用文件：`dist/wechat_astock_code.txt`**（`词语<TAB>编码<TAB>词频`）

### 还备选：自定义短语批量文件
若你的版本只有「自定义短语」而没有词库导入：

**用文件：`dist/custom_phrase_astock.txt`**（`编码,词频=词语`）
或 `dist/custom_phrase_astock_alt.txt`（`编码;词频,词语`）——两种历史写法都备着，看你版本认哪个。

### 验证
输入 `byd` → 候选应出现「比亚迪」；输入 `tclkj` → 出现「TCL科技」。

## 3. 搜狗输入法（Windows / 手机）

### 方案 A（推荐）：文本词库导入
**用文件：`dist/sogou_astock.txt`**（GBK 编码，行格式 `'编码 词语`）

1. 右键搜狗状态栏 → **属性设置**（或设置菜单）→ **词库**；
2. 选择 **导入词库 / 从文本导入**，文件指向 `sogou_astock.txt`；
3. 导入后 **重启输入法进程**（右下角退出再打开，或注销一次）让新词库生效。

> 该文件是 GBK 编码，别用 UTF-8 编辑器另存为，否则搜狗会读成乱码词。

### 方案 B：自定义短语
**用文件：`dist/custom_phrase_astock.txt`**（或 `_alt.txt`）

属性设置 → **高级** → **自定义短语** → **添加/导入** → 选 txt。
自定义短语数量大时（本词库 5647 条）建议先缩到几百条常用票：

```bash
python build.py all --freq hot --limit 500 --no-imewl
```

### 方案 C：细胞词库 `.scel`（当前**不推荐**）
搜狗官方的 `.scel` 导入是支持自定义编码的，但**深蓝词库转换 3.4 的 scel 导出实测有 bug**：
产物只有表头，5552 条回读只剩 2 条（详见 [formats.md 第 5 节](formats.md#5-关于-scel搜狗细胞词库)）。
本项目默认不导 scel。若你换到修好这个功能的版本，可以：

```bash
python build.py convert --targets scel,win10mspy
```

看 `[verify]` 回读条数是否等于导出条数，等于才可用。

## 4. 清库 / 回滚

| 输入法 | 删除方式 |
|---|---|
| 微软拼音 | 「管理用户自定义短语」里逐条删除；或先「导出」备份自己的，再删掉本项目的条目 |
| 微信输入法 | 词库管理里删除导入的记录；或退出登录重新同步（会丢弃本地导入） |
| 搜狗 | 词库管理里卸载/删除导入词库；自定义短语面板逐条删除 |

**别把两次构建的产物重复导入**，会出现两份一样的候选。想全量重导：先删干净，再导一次。

## 5. 常见问题

**Q：输入编码没反应？**
A：先确认输入法已经完全退出并重启（搜狗、微信都有词库缓存进程）；再用一个**新输入框**试，
有些程序里的输入框会一直用旧的候选记忆。仍无解就用 `--limit 300` 生成小词库单独导入做定位测试。

**Q：`stml` 出来的不是 `*ST美丽`？**
A：`.dat` 路径里词面被清洗成 `ST美丽`（深蓝会丢弃以 `*` 开头的词面，见 formats.md 第 4 节）。
文本词库 `sogou_astock.txt` / `wechat_astock_words.txt` 里两条都有，能进就能上屏官方名称。
如果你就是想让 `.dat` 也只保留官方名称，只能换别的转换工具或改深蓝源码。

**Q：候选里一堆股票挤在一起（`zykj` 有 13 只）？**
A：A 股重名是常态：`zykj` = 中一科技 / 中英科技 / 掌阅科技 / 长阳科技 … 用 `--freq hot` 让你常交易的热门票排前；
或者直接 `--exclude-st` + `--limit` 把长尾砍掉。

**Q：想要「输代码出名称」？**
A：`python build.py all --code-alias`，会追加 `000001 → 平安银行` 这类条目（词库会变大，按需开启）。

**Q：手机上行不行？**
A：`wechat_astock_words.txt` / `sogou_astock.txt` 都能直接传到手机导入；
`.dat` 是 Windows 微软拼音专属，手机上不适用。
